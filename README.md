# YA Tournament — سيرفر لوحة المراقبة المباشرة

سيرفر Node.js بسيط يستقبل تقارير من أداة **YA Security Scanner** (المُثبتة عند كل لاعب)
ويعرضها بلوحة مباشرة تتحدّث كل 3 ثوانٍ: مين متصل، درجة الاشتباه الحالية، وسجل التنبيهات.

## ⚠️ مبدأ الشفافية (مهم)
هذا السيرفر يستقبل فقط بيانات يرسلها **عميل الأداة طواعية وبعلم اللاعب** —
اللاعب لازم يدخل اسمه ورابط هذا السيرفر بنفسه بواجهة الأداة ويضغط "اتصال"،
وتبقى حالة الاتصال ظاهرة له طول الوقت. لا يُرسل أي ملفات أو بيانات شخصية —
فقط: اسم اللاعب، اسم الجهاز، ودرجة/سبب الاشتباه من نفس محرك الفحص السلوكي
(حقن DLL، درايفرات، Overlay، ذاكرة Manual Mapping) الموجود بالأداة.

## التشغيل محليًا (للتجربة)
```bash
cd TournamentServer
npm install
npm start
```
افتح المتصفح على: `http://localhost:3000`

## النشر لبطولة فعلية (يحتاج رابط عام يوصله كل اللاعبين)
اختر أي من:

### الخيار الأسهل: Render.com (مجاني للاستخدام الخفيف)
1. ارفع مجلد `TournamentServer` لمستودع GitHub خاص بك.
2. Render.com → New → Web Service → اربط المستودع.
3. Build Command: `npm install` — Start Command: `npm start`.
4. بعد النشر بتحصل رابط زي: `https://ya-tournament.onrender.com`.

### أو Railway.app / Fly.io
نفس الفكرة تقريبًا: ارفع المشروع، حدد `npm start` كأمر تشغيل، واحصل على رابط عام.

### أو VPS خاص بك
```bash
npm install --production
PORT=3000 node server.js
# يفضّل تشغيله خلف Nginx/Caddy مع HTTPS، وربطه بـ pm2 لإعادة التشغيل التلقائي:
npm install -g pm2
pm2 start server.js --name ya-tournament
```

## كيف يربط اللاعب الأداة بهذا السيرفر
1. يفتح `YA_SecurityScanner.exe`.
2. بشريط "اتصال البطولة" أعلى الواجهة: يكتب اسمه، ويكتب رابط السيرفر (مثل
   `https://ya-tournament.onrender.com`)، ويضغط "اتصال بسيرفر البطولة".
3. من هذي اللحظة، الأداة ترسل Heartbeat + أي تنبيه اشتباه تلقائيًا للسيرفر —
   وتظهر نقطة خضراء + رسالة "متصل" طول فترة الاتصال (شفاف بالكامل للاعب).

## ملاحظات إنتاجية
- التخزين حاليًا **في الذاكرة فقط** (يُمسح عند إعادة تشغيل السيرفر) — مناسب لبطولة
  قصيرة. لبطولات أكبر/أطول، أضف قاعدة بيانات حقيقية (SQLite بسيط أو Postgres).
- أضف طبقة مصادقة بسيطة (مثل رمز دخول للوحة `/index.html`) قبل مشاركة الرابط
  علنًا، حتى ما يشوف أحد النتائج غير المنظمين.
- الدرجات والمؤشرات هنا اجتهادية (Heuristics) — يُفضّل أن يراجع المنظّم يدويًا
  أي تنبيه قبل اتخاذ قرار إقصاء لاعب من البطولة.
